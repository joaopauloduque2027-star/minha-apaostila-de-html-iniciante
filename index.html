Olá! Eu estou aprendendo programação e criei esta apostila para registrar o que vou aprendendo sobre HTML. Compartilho aqui exemplos, imagens e links para acompanhar minha evolução.

HTML usa tags (como <h1>, <p>, <img>) para dizer ao navegador como organizar o conteúdo. Abaixo há seções com explicações e exemplos práticos.

Estrutura básica do HTML

Uma página HTML mínima tem a seguinte estrutura:

<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="utf-8">
    <title>Título da página</title>
  </head>
  <body>
    <h1>Olá</h1>
    <p>Primeiro parágrafo</p>
  </body>
</html>

Tags comuns

  • <h1> ... </h1> — títulos
  • <p> ... </p> — parágrafos
  • <img> — imagens (atributo alt obrigatório)
  • <a> — links
  • <section> <article> — organização semântica
  • <nav> — navegação

Link externo (com segurança)

Use rel="noopener" ou rel="noreferrer" em links que abrem em nova aba:

<a href="https://github.com/usuario" target="_blank" rel="noopener">GitHub</a>

Dicas rápidas

  • Evite nomes de arquivo com espaços: use foto-apresentacao.jpeg
  • Use textos alternativos descritivos em imagens (alt)
  • Valide seu HTML em validator.w3.org
