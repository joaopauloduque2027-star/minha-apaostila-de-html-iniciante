Como gerar PDF

Você pode salvar esta apostila em PDF usando o navegador ou automaticamente via um workflow (arquivo .github/workflows/generate-pdf.yml).

  • Método manual (recomendado): Abra o navegador → Menu → Imprimir → Salvar como PDF. Ajuste margens para "Padrão" e marque "Imprimir planos de fundo" para preservar cores.
  • Método automático (CI): O repositório contém um workflow GitHub Actions que gera apostila.pdf usando Puppeteer e disponibiliza como artefato.
Comando rápido (linha de comando) 
# Requer node e npm
npm install -g http-server puppeteer
# iniciar servidor na pasta do repositório
http-server -p 8080 &
# gerar PDF com Node + Puppeteer (exemplo simples)
node -e "const p=require('puppeteer');(async()=>{const b=await p.launch({args:['--no-sandbox']});const page=await b.newPage();await page.goto('http://127.0.0.1:8080',{waitUntil:'networkidle0'});await page.pdf({path:'apostila.pdf',format:'A4',printBackground:true});await b.close();})();"

Introdução

Esta apostila foi criada para iniciantes que querem compreender a estrutura do HTML e praticar com exemplos. Ela reúne explicações teóricas, exemplos práticos, exercícios comentados e instruções para gerar uma versão em PDF ou impressão, com foco em semântica e acessibilidade.

Estrutura básica do HTML

Todo documento HTML tem elementos essenciais: a declaração do doctype, a tag <html>, a seção <head> com metadados e a seção <body> com o conteúdo visível. Abaixo um exemplo mínimo:

<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Título da página</title>
  </head>
  <body>
    <h1>Olá Mundo</h1>
    <p>Meu primeiro parágrafo.</p>
  </body>
</html>

Tags importantes

Títulos e parágrafos

As tags <h1> até <h6> definem hierarquia de títulos. Use apenas um <h1> por página para o título principal e subsequentes para seções importantes.

Listas

Listas ordenadas (<ol>) e não ordenadas (<ul>) são usadas para agrupar itens (<li>).

Blocos semânticos

Use <header>, <nav>, <main>, <section>, <article>, <aside> e <footer> para estruturar o conteúdo de forma semântica — isso melhora a acessibilidade e o SEO.

Imagens e mídia

A tag <img> insere imagens. Sempre inclua o atributo alt para acessibilidade e escolha formatos otimizados (jpeg, webp). Forneça dimensões quando possível para evitar mudanças de layout.

<img src="foto-apresentacao.jpeg" alt="João Paulo sorrindo" width="300" />

Para áudio e vídeo, use <audio> e <video> com controles e mensagem de fallback:

<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
  Seu navegador não suporta o elemento audio.
</audio>

<video controls width="480" poster="poster.jpg">
  <source src="video.mp4" type="video/mp4">
  Seu navegador não suporta o elemento video.
</video>

Links e navegação

Links são criados com <a>. Para abrir em nova aba, use target="_blank" e para segurança adicione rel="noopener noreferrer". Para navegação interna use âncoras (hash).

<a href="https://github.com/usuario" target="_blank" rel="noopener noreferrer">Meu GitHub</a>

Formulários

Formulários permitem entrada de dados. Sempre valide no cliente e no servidor, use tipos de input apropriados e proteja contra CSRF.

<form action="/enviar" method="post">
  <label>Nome<input type="text" name="nome" required></label>
  <label>Email<input type="email" name="email" required></label>
  <button type="submit">Enviar</button>
</form>

Dicas: valide no cliente e servidor; proteja contra CSRF; não confie apenas em JavaScript.

Semântica e acessibilidade

HTML semântico ajuda a SEO e leitores de tela. Use atributos ARIA quando necessário e sempre textos alternativos para imagens. Teste com leitores de tela e valide a ordem de foco.

<article>
  <h2>Título do artigo</h2>
  <p>Autor: João Paulo</p>
  <p>Conteúdo do artigo...</p>
</article>

Boas práticas
  • Use nomes de arquivos sem espaços e minúsculos (ex.: foto-apresentacao.jpeg).
  • Forneça alt descritivo para imagens.
  • Teste em diferentes tamanhos de tela (responsivo).
  • Valide o HTML em validator.w3.org.
  • Minimize dependências externas e cuide de desempenho (compressão, lazy-loading).

Exercícios
  1. Crie uma página com título, dois parágrafos e uma imagem com legenda.
  2. Faça um formulário simples de contato com validação do tipo de input.
  3. Monte uma pequena galeria de imagens com <figure> e <figcaption>.

Soluções (resumidas)

Ex.1 — Estrutura mínima com imagem e legenda:

<h1>Minha página</h1>
<p>Parágrafo 1</p>
<p>Parágrafo 2</p>
<figure>
  <img src="foto.jpg" alt="Descrição" width="300">
  <figcaption>Legenda da imagem</figcaption>
</figure>
