    <p>Olá — seja bem-vindo(a)! Esta é uma apostila de introdução ao HTML com exemplos e exercícios para quem está começando.</p>
    <p>Sinta-se à vontade para navegar pelos tópicos, praticar e acompanhar a evolução do material.</p>

  <main>
    <section id="introducao">
      <h2>Introdução</h2>
      <p>HTML (HyperText Markup Language) é a linguagem de marcação usada para estruturar páginas na web. Nesta apostila vamos cobrir desde a estrutura básica até elementos semânticos e formulários.</p>
    </section>

    <section id="estrutura">
      <h2>Estrutura básica de um documento HTML</h2>
      <pre><code>&lt;!DOCTYPE html&gt;
&lt;html lang="pt-BR"&gt;
  &lt;head&gt;
    &lt;meta charset="utf-8"&gt;
    &lt;title&gt;Título da página&lt;/title&gt;
  &lt;/head&gt;
  &lt;body&gt;
    Conteúdo da página
  &lt;/body&gt;
&lt;/html&gt;</code></pre>
      <p>O <code>&lt;!DOCTYPE html&gt;</code> informa ao navegador que estamos usando HTML5; o elemento <code>&lt;html&gt;</code> envolve toda a página; o <code>&lt;head&gt;</code> contém metadados; e o <code>&lt;body&gt;</code> contém o conteúdo visível.</p>
    </section>

    <section id="texto-formatação">
      <h2>Texto e formatação</h2>
      <p>Tags comuns para texto:</p>
      <ul>
        <li><code>&lt;h1&gt;...&lt;/h1&gt;</code> até <code>&lt;h6&gt;</code> — títulos</li>
        <li><code>&lt;p&gt;</code> — parágrafos</li>
        <li><code>&lt;strong&gt;</code> e <code>&lt;em&gt;</code> — destaque semântico</li>
        <li><code>&lt;small&gt;</code>, <code>&lt;sub&gt;</code>, <code>&lt;sup&gt;</code> — pequenos formatos</li>
      </ul>
    </section>

    <section id="imagens-links">
      <h2>Imagens e links</h2>
      <p>Inserir imagens com <code>&lt;img src="url" alt="texto"&gt;</code>. Sempre inclua o atributo <code>alt</code> para acessibilidade.</p>
      <p>Criar links com <code>&lt;a href="url"&gt;texto&lt;/a&gt;</code>. Para abrir em nova aba, use <code>target="_blank"</code> e <code>rel="noopener noreferrer"</code>.</p>
    </section>

    <section id="listas-tabelas">
      <h2>Listas e tabelas</h2>
      <p>Listas não ordenadas: <code>&lt;ul&gt;</code>; listas ordenadas: <code>&lt;ol&gt;</code>. Tabelas: <code>&lt;table&gt;</code>, <code>&lt;thead&gt;</code>, <code>&lt;tbody&gt;</code>, <code>&lt;tr&gt;</code>, <code>&lt;th&gt;</code>, <code>&lt;td&gt;</code>.</p>
    </section>

    <section id="formularios">
      <h2>Formulários</h2>
      <p>Formulários coletam dados do usuário com <code>&lt;form&gt;</code>, campos como <code>&lt;input&gt;</code>, <code>&lt;textarea&gt;</code>, <code>&lt;select&gt;</code> e botões <code>&lt;button&gt;</code>. Sempre associe <code>&lt;label&gt;</code> aos campos para acessibilidade.</p>
    </section>

    <section id="semantica-acessibilidade">
      <h2>Semântica e acessibilidade</h2>
      <p>Use elementos semânticos (<code>&lt;header&gt;</code>, <code>&lt;nav&gt;</code>, <code>&lt;main&gt;</code>, <code>&lt;section&gt;</code>, <code>&lt;article&gt;</code>, <code>&lt;footer&gt;</code>) para estruturar a página. Adicione atributos ARIA quando necessário e textos alternativos para imagens.</p>
    </section>

    <section id="css-introducao">
      <h2>Breve introdução ao CSS</h2>
      <p>CSS (Cascading Style Sheets) é usado para estilizar HTML. Pode ser incluído inline, em &lt;style&gt; no &lt;head&gt; ou em arquivos externos linkados com <code>&lt;link rel="stylesheet" href="estilos.css"&gt;</code>.</p>
    </section>

    <section id="exercicios">
      <h2>Exercícios</h2>
      <ol>
        <li>Crie uma página HTML com sua apresentação: nome, uma foto e uma lista de hobbies.</li>
        <li>Adicione um formulário simples para contato (nome, email, mensagem).</li>
        <li>Crie uma tabela com uma pequena agenda semanal.</li>
      </ol>
    </section>
